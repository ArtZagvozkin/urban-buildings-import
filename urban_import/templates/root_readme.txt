КОМПЛЕКТ ОДИНЦОВСКОГО ОКРУГА: ЧЕТЫРЕ WORKER, ПЕРЕМЕННОЕ ЧИСЛО ПК

Worker ID принадлежит папке, не компьютеру. Можно начать с node-1 и
node-2 на двух ПК; node-3/4 запускаются позже на любом свободном ПК.
Разные worker-папки разрешено выполнять одновременно или последовательно на
одном ПК. До общей стадии уже запущенные worker ждут через GET к URBAN API.
Сначала выполните run.ps1 -DryRun. Реальная запись закрыта до отдельного
подтверждения полноты частей 1-4 и явного разрешения POST/DELETE.

После завершения верните четыре ZIP в один каталог. На основном узле:
  collect-results.ps1 -ResultsDirectory <каталог>
  verify-final.ps1

Один worker ID нельзя выполнять одновременно из двух копий папки. При переносе
сначала остановите старый процесс, затем копируйте всю папку с состоянием.
