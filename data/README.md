# Исходные данные

В `raw/` находятся 14 исходных GeoJSON, предоставленных для проекта:
по два файла Реутова, Жуковского и Лотошина и восемь файлов частей Одинцова.
Имена содержат территорию, часть и назначение. Содержимое не редактируется;
контрольные суммы записаны в компактных результатах. Преобразование переводов
строк для этих файлов отключено в .gitattributes.

Пути, назначения и исходные количества задаёт config/territories.json.
Достоверные дата извлечения OSM и версия инструмента выгрузки не предоставлены.
Требуемые координаты — долгота/широта WGS84; геодезические площади — м².
Проверка, исключения и допустимые исправления описаны в docs/rules.md.

Для повторения завершённого результата используются сохранённые муниципальные
границы reference/boundaries. Решения подготовки и тела запросов проверяются
по контрольным суммам; обработанные копии исходников в Git не нужны.
